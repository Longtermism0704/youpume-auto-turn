有谱么自动翻谱 · 隐私政策

最后更新：2026-11-22　适用版本：2.3.0 及以上

本扩展「有谱么自动翻谱（Auto Scroll）」（以下简称"本扩展"）是一款仅在 yopu.co 曲谱页面上提供"自动向下滚动翻谱"功能的浏览器辅助工具。我们非常重视您的隐私，本政策说明本扩展如何处理数据。

一、我们不收集任何个人信息

本扩展不收集、不存储、不上传、不共享任何个人身份信息，包括但不限于：姓名、账号、密码、邮箱、浏览历史、以及您访问的曲谱内容。本扩展没有任何服务器端，所有处理均在您的浏览器本地完成。

二、本扩展在本地存储什么

为记住您上次的速度偏好，本扩展会在您的浏览器本地（chrome.storage.local）保存一个滚动速度数值（像素/秒）。该数据：

  • 仅保存在您本机浏览器中，绝不上传；
  • 不含任何可识别您身份的信息；
  • 可在卸载扩展后被浏览器一并清除。

三、本扩展访问什么

本扩展仅在 yopu.co 与 www.yopu.co 域名下生效，用于读取页面中曲谱滚动区域的尺寸并让页面自动滚动。它不会读取、修改或向外发送页面中的任何内容。

四、权限说明

  • storage：保存您的速度偏好（本地）。
  • scripting / activeTab：在您点击扩展图标时，向当前曲谱页注入滚动逻辑（仅在 yopu.co 生效）。
  • host_permissions（yopu.co）：限定本扩展只在曲谱站点工作。

五、第三方

本扩展不集成任何第三方统计、广告或分析 SDK。

六、免责声明

本扩展为个人辅助工具，与 yopu.co 官方无隶属关系，仅帮助用户在浏览曲谱时被动向下滚动，不提供任何下载、破解或内容提取功能。用户应在遵守目标网站服务条款的前提下使用。

七、联系方式

如对本隐私政策有任何疑问，可通过扩展商店页面留言或邮件联系开发者。
