# 有谱么自动翻谱插件 (v2.2)

在 [yopu.co](https://yopu.co) 曲谱查看页（如 `/view/xxxx`）自动向下滚动翻谱，支持调速、暂停/继续。

## 功能

- **自动翻谱**：曲谱页自动向下平滑滚动。
- **按「整首用时」调速**：设定这首歌大约弹多久滚到底（如 5 分钟），自动换算速度；「快一点 / 慢一点」微调。
- **暂停 / 继续 / 回到顶部**。
- **后台持续滚动**：切到别的标签页/窗口也不中断（Web Worker 计时，规避 Chrome 后台冻结）。
- **快捷键**：滚动时按「空格」暂停 / 继续。
- 自动适配站点：优先 `#nier-scroll-view` 容器，找不到时自动选最大的可滚动区域；SPA 切换曲谱自动重新探测。

## 安装 / 更新

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 右上角打开「**开发者模式**」。
3. 首次安装：点「**加载已解压的扩展程序**」，选择本文件夹（含 `manifest.json`）。
   - **更新已有安装**：找到本插件卡片，点「**刷新**」↻ 按钮即可（会重新读取本文件夹的最新代码）。
4. 打开曲谱页 → 点工具栏的插件图标 → 在弹出的面板上点「开始滚动」。

> 更新后如果曲谱页无反应，**刷新该曲谱页**（F5）即可让新代码生效。

## 使用

1. 打开曲谱页（如 https://yopu.co/view/3PbjG3gP）；
2. 点浏览器工具栏的插件图标，在弹窗里拖动「整首谱滚动时长」滑块（值越小滚得越快），点「开始滚动」；
3. popup 会自动关闭，曲谱页开始向下滚动；需要停下再点图标点「暂停」，或直接按空格；「回到顶部」重新开始。

## 排查「翻不动」

- 确认插件已启用；更新后在 `chrome://extensions` 点本插件「刷新」，再 **F5 刷新曲谱页**。
- 曲谱完整内容需要登录；未登录只见预览片段，滚到预览末尾会停（下方有「登录/创建账号」提示）——这是站点限制，不是插件问题。

## 说明

- 版本：Manifest V3，适配新版 Chrome（MV2 已被新版 Chrome 停用）。
